A dark high-fantasy block theme for OpenMU (MU Online server emulator) websites, with an animated eclipse scene.

== Description ==

OpenMU Eclipse is a standalone block theme: an animated eclipse hero, a three-class showcase, a glassy sticky header, a news section and ready-made pages (ranking, mini games, armory, events, commands, download, account). It styles all blocks of the OpenMU WP Connect plugin. All graphics are original. Fonts are bundled; the theme makes no external requests.

On activation it creates the pages by address (home, news, download, ranking, mini-games, armory, events, commands, account) and sets the front page and the posts page.

== Installation ==

1. Upload the theme folder to wp-content/themes/ and activate it.
2. Optionally install the OpenMU WP Connect plugin for live server data.
3. Replace the placeholder links (Download page buttons, Discord) in the editor.

== Frequently Asked Questions ==

= Does it work without the plugin? =
Yes. Sections that need game data then show a short notice.

= Does the animation slow phones down? =
Particles are capped and halved on small screens, animation pauses in a hidden tab and stops with prefers-reduced-motion.
